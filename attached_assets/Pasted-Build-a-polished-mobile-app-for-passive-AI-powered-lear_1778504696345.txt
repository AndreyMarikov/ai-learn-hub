## CORE EXPERIENCE

The user creates learning chats/topics.

Examples:

* “I want to learn Japanese.”
* “Teach me investing.”
* “I want to understand physics.”

The AI then conversationally gathers missing information.

The app MUST use a Gemini model (Google Gemini) as the AI engine for all conversations and learning logic.

The Gemini model is responsible for:

* understanding user intent
* asking follow-up questions when needed
* extracting structured learning preferences
* determining when enough information has been collected
* generating the final learning configuration

Possible follow-up questions:

* beginner/intermediate/advanced?
* casual or serious?
* practical or theoretical?
* learning goals?
* preferred frequency?
* quiet hours for notifications?

The conversation should feel natural, intelligent, and adaptive.

Once enough information is collected, the AI responds:

“Your learning flow is ready. If you want to change anything later, just tell me.”

After that:

* show a learning summary card
* show an “Add Widget” button nearby

---

## IMPORTANT PRODUCT BEHAVIOR

The app is NOT for active studying.

The goal is passive learning throughout the day using:

* widgets
* notifications
* small learning snippets
* background reinforcement

The onboarding chat is used to configure a personalized learning stream.

The Gemini model should internally structure the user’s preferences into a learning profile containing:

* topic
* skill level
* intensity
* learning style
* notification frequency
* quiet hours
* goals

The user should NOT see raw JSON.
